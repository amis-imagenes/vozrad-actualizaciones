# VozRad – actualizaciones

Canal público de actualizaciones de VozRad (reconocimiento de voz para radiología, AMIS).

- `VozRad-X.Y.Z-actualizacion.zip`: el programa completo de esa versión (sin datos de usuario).
- `VozRad-X.Y.Z-novedades.txt`: qué cambió.

VozRad revisa este repositorio cada hora y ofrece la versión nueva en su panel
(«★ Versión nueva · Actualizar»). Aquí no hay informes, audios ni datos de pacientes.
Se conservan solo las últimas 3 versiones.
